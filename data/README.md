# data/

Everything the ML pipeline reads and writes. Paths resolve from here via
`backend/app/config.py` (`DATA_DIR`, overridable with an env var).

| path | contents | git |
|---|---|---|
| `mall_dataset/` | extracted Mall Dataset frames — `frames/*.jpg` | ignored |
| `mall_dataset.zip` | the original download; unzip into `mall_dataset/` | ignored |
| `test_mall.mp4` | the 2-minute clip used for local demos | ignored |
| `labels/samples.csv` | 86 hand-labeled visits (`label` = 1 anomaly / 0 normal) | tracked |
| `labels/results.json` | precision/recall from `backend/scripts/score_labels.py` | tracked |
| `labels/worksheet_*.png` | sketches used while labeling | tracked |
| `out/heatmaps/` | `mall_{full,morning,afternoon,evening}.png` — all 2000 frames | tracked |
| `out/training/autoencoder_training.png` | loss curve + reconstruction-error histogram | tracked |
| `mall_positions.json`, `trajectories.json` | regenerated by `backend/scripts/build_*.py` | ignored |
| `shoplens.db` | SQLite database (zones, analytics, anomalies, reports) | ignored |

Videos uploaded through the app do **not** land here — they go to `../storage/`.
