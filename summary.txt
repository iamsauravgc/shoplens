TRACKING SUMMARY
================
Dataset:        Mall Dataset (CUHK), frames 1-200
Detector:       YOLOv8n, conf=0.1
Tracker:        DeepSORT

Best parameters:
  max_age:      50
  n_init:       5

Results (200 frames):
  Unique IDs (baseline max_age=30, n_init=3): 208
  Unique IDs (best config):                   103
  Reduction in ID switches:                   105

Why fewer unique IDs = better:
  Each re-assignment of a new ID to the same physical person
  is an ID switch. Fewer total IDs across the same 200 frames
  means the tracker kept the same person under the same ID longer.

Known limitations:
  - Occlusion (people overlapping) causes temporary ID loss
  - Top-down angle reduces appearance embedding quality
  - DeepSORT re-assigns a new ID when a person re-enters after max_age frames
